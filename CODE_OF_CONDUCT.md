# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, verbatim, as
its code of conduct. The canonical text lives at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

We don't vendor a local copy so that future amendments to the canonical
document take effect automatically.

## Reporting

If you experience or witness behaviour that violates the Covenant, please
report it using GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository (yes, the same channel as security issues — it's the
only private inbox we have). Reports are reviewed by the maintainers
listed in [`CODEOWNERS`](.github/CODEOWNERS).

We follow the **Enforcement Guidelines** in the Covenant text (sections
on Correction, Warning, Temporary Ban, and Permanent Ban) for any
violation we substantiate.
